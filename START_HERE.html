AIBET MONEY · С АДМИНКОЙ

Всё редактируется
в одной панели.

Тексты, обложки, коэффициенты, результаты и настройки. После подключения вручную менять файлы в GitHub для публикаций не понадобится.

1. Загрузи сайт

Загрузи содержимое папки проекта в GitHub. В корне обязательно должны лежать .pages.yml, _config.yml и index.html.

Для первого запуска: Settings → Pages → Deploy from a branch → main → /(root) → Save.

Если сайт уже работает, обнови его файлами этого архива. Существующие статьи не удаляй.

2. Подключи панель

Открой app.pagescms.org → вход через GitHub → подключение приложения Pages CMS.

Выбери Only select repositories и укажи репозиторий сайта. Затем открой его и ветку main в Pages CMS.

3. Работай в админке

Открой «Разборы матчей», создай статью, добавь картинку, включи «Показывать на сайте» и сохрани. CMS сама запишет изменения, GitHub автоматически пересоберёт сайт.

Главный экран и Telegram меняются в «Настройки сайта».

Панель администрирования находится в Pages CMS. На сайте будет ссылка «Админка». Вход проверяет GitHub, пароля в файлах сайта нет. Сервису нужен доступ к изменению файлов выбранного репозитория.

Выключенная публикация скрывает страницу на сайте, но не исходный файл в публичном GitHub. Это решение для открытых материалов. Полная инструкция — README.md.
