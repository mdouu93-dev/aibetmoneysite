# Проверка главной страницы и конфигурации админки

1 ноября 2026 года.

Главная заново собрана по дизайн-системе AiBet Money: navy / platinum, Montserrat / Inter, ограниченное золото, крупная типографика, входы в футбол и хоккей, отдельный блок главного разбора и метод в виде строк. Логотип и знак извлечены из исходного PDF, прежняя упрощённая геометрия удалена.

Проверено локально:

- YAML конфигурации CMS и соответствие редактируемых полей данным сайта.
- Шаблоны Liquid через LiquidJS: пустая и заполненная коллекции, выбор главного разбора, исключение черновиков, все три завершённых результата, отсутствие пустой ставки в главном блоке, необязательные поля и ссылка на калькулятор.
- Формат коэффициентов, нулевой счёт, московское время, JSON-LD и внутренние ссылки с префиксом /aibetmoneysite/.
- В браузере: композиция главной, мобильное меню и Escape, фильтр по спорту, отсутствие горизонтальной прокрутки страницы на узком экране.

Тестовые статьи и вспомогательные страницы проверки не включены в публикуемые исходники. Локальная проверка LiquidJS не заменяет настоящую сборку Jekyll; её результат показывает GitHub Actions после отправки изменений.

Отправить обновление через подключение GitHub в ChatGPT не удалось: GitHub вернул HTTP 403 «Resource not accessible by integration». Код в main и действующий сайт не обновлены. Для автоматической отправки нужен проект Codex с доступом к репозиторию; обычное подключение GitHub в ChatGPT предоставляет чтение. Готовые исходники приложены для переноса без повторной разработки.

Вход владельца в Pages CMS, установка приложения Pages CMS и сохранение через её интерфейс отдельно не проверялись. Конфигурация готова; порядок подключения и тест публикации описаны в README.

published: false управляет выводом страницы Jekyll. В публичном репозитории исходники и изображения всё равно доступны. Не использовать для приватных материалов или хранения секретов.
